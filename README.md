# 三角形內角探索 · 星圖研究室

[開啟教具](https://wcy.hk/Exploring-interior-angles-of-triangles/)

日系動漫研究學院風格，移除真人同事頭像及姓名。拖曳 A、B、C 頂點，即時探索角度；8 個步驟逐一收集內角，最後拼成 180°。可隱藏 C 角作課堂挑戰。支援觸控與鍵盤方向鍵，Shift 加大移動幅度。

幾何使用向量 atan2 計算真實內角，拒絕頂點重疊、共線及小於 8° 的退化形狀。顯示整數採最大餘數法，三個數字仍相加 180；拼圖使用真實角度。拖曳保留探索步驟，重設回初始三角形及第 1 步。

純靜態 GitHub Pages，無後端。測試：`node --test geometry.test.mjs`。插圖為 WCY.HK 原創專案海報。
